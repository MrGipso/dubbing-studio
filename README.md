# Dubbing Studio

Локальный дубляж видео и аудио на своём компьютере:

```
видео ─► отделение голоса от фона ─► Whisper ─► любая LLM (перевод) ─► любой TTS-движок (озвучка) ─► видео с дубляжом
```

- **Проекты.** Каждый ролик — папка с исходником, переводом, озвучкой и
  готовым видео. Мастер в четыре шага: исходник → голос → перевод → результат.
- **Несколько языков в одном проекте.** Ролик распознаётся один раз, а
  перевод, озвучка и готовое видео делаются для каждого языка. Добавленный
  позже язык не трогает уже готовые.
- **Перевод любой моделью.** LM Studio, Ollama, llama.cpp, KoboldCpp, Jan, vLLM
  или облако по ключу: OpenRouter (Claude, Gemini, GPT, DeepSeek, Qwen…),
  OpenAI, DeepSeek, Groq, Gemini. Плюс любой OpenAI-совместимый сервер.
- **Озвучка любым движком.** В комплекте OmniVoice (646 языков, точное
  попадание в длительность), Chatterbox Multilingual (23 языка, лицензия MIT) и
  «любой сервер `/v1/audio/speech`» (Kokoro-FastAPI, openedai-speech и др.).
  Свой движок подключается папкой с двумя функциями.
- **Голос оригинала.** Образец для клонирования программа вырезает из ролика
  сама и предлагает несколько отрывков на выбор. Можно взять свой образец или
  готовый голос движка.
- **Несколько говорящих.** Программа сама находит, кто и когда говорит, и
  озвучивает каждого его собственным голосом. Говорящего у любой фразы можно
  поменять вручную.
- **Фон остаётся.** Demucs отделяет голос от музыки и шумов: музыка и шумы
  оригинала сохраняются в готовом ролике, а голос заменяется переводом.
- **Подгонка под тайминги.** Длинные фразы ускоряются движком или
  растягиваются во времени без смены тона. Паузы очищаются от шумов,
  громкость выравнивается до −16 LUFS.
- **Быстрая переозвучка.** Модель озвучки остаётся загруженной несколько минут
  после работы, поэтому правка одной фразы переозвучивается за секунды.
- **Интерфейс на русском и английском.** Язык переключается внизу боковой панели.

## Что нужно

- Windows 10/11, macOS или Linux. Проверено на Windows. В macOS и Linux
  запуск через `setup.sh` / `start.sh`: программа написана на Python и ffmpeg
  без системных скриптов, но там её пока никто не проверял.
- [uv](https://docs.astral.sh/uv/) — ставит Python и зависимости сам.
- [ffmpeg](https://ffmpeg.org/) в `PATH`.
- Видеокарта NVIDIA желательна: Whisper и движки работают и на процессоре, но медленно.
- Модель перевода: локальная (например LM Studio с любой instruct-моделью) или ключ облачного сервиса.

## Установка

**Windows, проще всего:** скачайте установщик `…_x64-setup.exe` из
[последнего релиза](https://github.com/MrGipso/dubbing-studio/releases/latest)
и запустите. Он не подписан, поэтому Windows может предупредить о неизвестном
издателе: «Подробнее» → «Выполнить в любом случае». Права администратора не нужны. При первом запуске
программа сама подготовит Python, распознавание речи и ffmpeg, это около
полуминуты с быстрым интернетом. Потом она открывается в своём окне, как
обычное приложение. Проекты лежат в `Документы\Dubbing Studio`. Как устроена
и собирается десктопная версия: [desktop/README.md](desktop/README.md).

**Windows из исходников:**

```bash
winget install --id=astral-sh.uv -e
```

```bash
winget install --id=Gyan.FFmpeg -e
```

Затем скачайте проект и запустите `Setup.bat` (один раз), потом `Start_UI.bat`.

macOS / Linux:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

```bash
./setup.sh
```

```bash
./start.sh
```

Откроется `http://127.0.0.1:8768`.

При первом запуске откроются **Настройки**:

1. **Перевод (LLM).** Выберите, где работает модель, выберите модель из списка
   и нажмите «Проверить подключение». Для облака вставьте API-ключ: он хранится
   только у вас, в `config/secrets.local.json`.
2. **Озвучка (TTS).** Выберите движок и нажмите «Установить движок»: он
   поставится в свою папку со своим окружением. Если модель у вас уже стоит,
   укажите путь к её `python.exe`. Проверьте кнопкой «Озвучить пробную фразу».
   «Держать модель загруженной» задаёт, сколько минут модель ждёт следующей
   задачи (0 — выгружать сразу).
3. **Отделение голоса от фона.** Установите Demucs. Без него проект тоже
   работает, но фон оригинала в ролик не попадёт.
4. **Разделение на говорящих.** Установите Sherpa-ONNX, если в роликах говорят
   несколько человек. Он лёгкий (около 100 МБ), работает на процессоре и не
   требует токенов.
5. **Whisper.** Модель распознавания: `medium` — баланс, `large-v3` — точнее.

## Как сделать дубляж

1. **Проекты → Новый дубляж:** перетащите видео или аудио и выберите язык перевода.
2. **Исходник:** при желании добавьте ещё языки («+ Добавить язык…»). Если в
   ролике говорят несколько человек, в поле «Говорящие» выберите «Найти
   автоматически» или точное число. Затем нажмите «Распознать и перевести»
   — или «Сделать всё сразу», если готовы довериться настройкам по умолчанию. Когда языков несколько, над шагами
   появляются вкладки языков: шаги «Голос», «Перевод» и «Результат» относятся
   к выбранной вкладке.
3. **Голос:** голос оригинала (по умолчанию), свой образец или голос движка →
   «Озвучить». Если образец оригинала звучит неудачно, стрелки под ним
   переключают отрывок. Когда говорящих несколько, у каждого своя строка:
   имя, сколько он говорит и какой голос выбран; «Изменить» раскрывает выбор.
   Тому, кто говорит только короткими фразами, образец склеивается из
   нескольких его фраз.
4. **Перевод:** временная шкала и редактор фраз. На шкале поверх волны звука
   видны все фразы в цвете говорящего, рамка показывает, как фраза легла в
   тайминг (ускорена — жёлтая, обрезана — красная, изменена — пунктир). Клик
   по фразе находит её в таблице и проигрывает; переключатель «Оригинал /
   Озвучка» выбирает, что слушать. Перевод правится прямо в таблице.
   «Сократить» просит модель ужать фразу под её длительность (для всех
   длинных фраз сразу — «Сократить длинные»). «Переозвучить изменённые»
   озвучивает заново только правленые фразы и пересобирает ролик. Если
   программа ошиблась с говорящим, выберите другого в списке под временем фразы.
5. **Результат:** громкость голоса, фона и музыки → «Собрать». Переключатель
   «Дубляж / Оригинал» над плеером сравнивает их с того же места. Готовое
   видео, звук, отдельный голос и субтитры каждого языка можно скачать или
   открыть в папке проекта.

Внизу всегда видна строка прогресса: шаг и проценты. Кнопка «Стоп» прерывает задачу.

**Инструменты** — отдельные операции без проекта: перевод и озвучка текста,
сценарий с эмоциями, транскрибация, обработка голоса, сведение с музыкой.

## Перевод: какие модели подходят

Все этапы, где нужна модель, используют один клиент (`llm_client.py`) и одну
настройку. Готовые пресеты лежат в `config/llm_providers.json`, новый сервис
добавляется одной записью.

| Где | Адрес по умолчанию | Ключ | Загрузка/выгрузка модели |
|---|---|---|---|
| LM Studio | `http://127.0.0.1:1234/v1` | — | да, автоматически |
| Ollama | `http://127.0.0.1:11434` | — | выгрузка после работы |
| llama.cpp / KoboldCpp / Jan / vLLM | свой порт | — | нет |
| OpenRouter, OpenAI, DeepSeek, Groq, Gemini | облако | да | — |
| Другой OpenAI-совместимый сервер | любой | по желанию | нет |

Ответы запрашиваются по JSON-схеме (structured output). Поэтому даже
маленькие локальные модели возвращают корректный результат. Если сервер схему
не понимает, клиент сам переходит на обычный запрос. Переводчик видит
несколько уже переведённых соседних фраз, так что термины и имена не скачут.
Когда говорящих несколько, модель знает, кто говорит каждую фразу, и держит
для каждого один род и одну манеру речи. Фразы разных людей в одну не
склеиваются.

Ключи никогда не передаются в командной строке. Источники ключа по порядку:
переменная `DUB_LLM_API_KEY`, переменная сервиса (`OPENROUTER_API_KEY`,
`OPENAI_API_KEY`, …) и `config/secrets.local.json`.

Локальной модели перевода и модели озвучки нужна одна видеокарта. Поэтому
перед распознаванием и переводом на локальной модели загруженная модель
озвучки выгружается сама, а модель перевода выгружается после работы
(настройка «Выгружать после работы»).

## Движки

| Движок | Назначение | Клон голоса | Длительность | Лицензия |
|---|---|---|---|---|
| OmniVoice | озвучка, 646 языков | да | точная | код Apache-2.0, **веса CC-BY-NC** |
| Chatterbox Multilingual | озвучка, 23 языка | да | подгоняет ядро | **MIT**, можно в коммерции |
| Любой сервер `/v1/audio/speech` | озвучка | голоса сервера | подгоняет ядро | зависит от сервера |
| Demucs | отделение голоса от фона | — | — | **MIT** |
| Sherpa-ONNX | кто и когда говорит | — | — | **Apache-2.0**, сегментация pyannote **MIT** |

Как добавить свой движок: [engines/README.md](engines/README.md). Коротко —
скопировать `engines/_template`, описать модель в `engine.json`, написать
`load()` и `synthesize()` (или `separate()` для отделения фона, `diarize()`
для разделения на говорящих). Поля настроек интерфейс построит сам.

> **Лицензии моделей.** Программа бесплатная, но лицензии моделей задают их
> авторы. Веса OmniVoice разрешены только для некоммерческого использования. Если
> дублированные ролики приносят доход, выбирайте движок с открытой лицензией
> (например Chatterbox) и проверьте условия выбранной модели перевода.
> Клонируйте только голоса, на которые у вас есть согласие владельца.

## Язык интерфейса

Тексты интерфейса написаны в коде по-русски, переводы лежат в
`locales/<код>.json` в виде `{"русский текст": "перевод"}`. Тот же словарь
переводит сообщения проекта в логе. Пока язык не выбран вручную, он берётся
из языка браузера: русский для ru/uk/be/kk, иначе английский.

Как добавить язык:

1. Скопируйте `locales/en.json` в `locales/<код>.json` (например `de.json`) и
   переведите значения. Ключи не меняйте, а `{name}`-подстановки сохраните.
2. Проверьте, что ничего не пропущено:

```bash
uv run python tests/test_i18n.py --missing de
```

Новый язык сразу появится в переключателе. Тест `tests/test_i18n.py` следит,
чтобы у каждой строки интерфейса был перевод.

## Командная строка

```bash
python project.py create clip.mp4 --target English --target Spanish --speakers 0
```

```bash
python project.py run projects/<id> all
```

```bash
python llm_client.py --llm-provider ollama --list-models
```

```bash
python dub.py projects/<id>/work/transcript.en.dub.jsonl --engine chatterbox --auto-fit --ref-audio voice.wav
```

```bash
python tts_engines.py --engine omnivoice --language en --text "Hello there"
```

Этапы проекта:

- `prepare` — звук → отделение фона → Whisper → говорящие → образцы голосов → перевод на все языки;
- `translate` — перевести на языки, которых ещё нет (например только что добавленный);
  если изменилось число говорящих, сначала заново находит их;
- `voice` — озвучка;
- `export` — сведение и сборка видео;
- `all` — всё, что ещё не сделано;
- `shorten` — сократить длинные фразы через модель перевода;
- `revoice` — переозвучить изменённые фразы и пересобрать ролик.

`--speakers`: `1` — один голос на всех (по умолчанию), `0` — найти говорящих
автоматически, `N` — ровно N человек. `--targets Spanish,German` ограничивает
этап этими языками. Для `shorten` и
`revoice` можно указать фразы: `--ids 3,5`. Настройки движков берутся те же,
что выбраны в интерфейсе.

## Структура

```
pipeline_ui.py        локальный сервер интерфейса (127.0.0.1)
paths.py              где программа хранит данные (рядом с кодом или в папках десктопа)
tools_setup.py        скачивание ffmpeg
desktop/              десктопная версия: оболочка Tauri, экран первого запуска, сборка установщика
ui/                   интерфейс: core.js, projects.js, tools.js, settings.js, i18n.js
locales/              переводы интерфейса (en.json, ...)
i18n.py               язык интерфейса и сообщений
project.py            проекты и их этапы
app_settings.py       общие настройки (config/settings.local.json)
llm_client.py         единый клиент LLM + config/llm_providers.json
translate_srt.py      перевод субтитров по фразам с таймингами
dub.py                ядро озвучки: тайминги, подгонка, сведение фраз
tts_engines.py        реестр движков, клиент воркера, «тёплая» модель
engines/              движки озвучки, отделения фона и разделения на говорящих (каждый в своём окружении)
tests/                тесты без моделей и видеокарты
```

Папка проекта:

```
projects/<дата>_<название>/
  project.json   настройки, говорящие и их голоса, состояние каждого языка
  source/        исходник
  work/          звук, голос, фон; whisper.json — распознанный текст, transcript.json —
                 фразы с говорящими; переводы и озвученные фразы по языкам
  voice/         образцы голосов (original_s1.wav, original_s2.wav, ...)
  output/        видео с дубляжом, сведённый звук, голос и субтитры для каждого языка
```

Тесты:

```bash
uv run python -m unittest discover tests
```

## Известные ограничения

- Когда два человека говорят одновременно, фраза достаётся одному из них.
- На очень похожих голосах автоматический подсчёт говорящих может ошибиться:
  тогда укажите их число вручную или поправьте говорящих у фраз.
- В macOS и Linux программа не проверялась.
- Python 3.10–3.12 для основного окружения (`uv` выберет сам).
