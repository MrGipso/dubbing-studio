# Dubbing Studio

Локальный дубляж видео и аудио на своём компьютере:

```
видео ─► отделение голоса от фона ─► Whisper ─► любая LLM (перевод) ─► любой TTS-движок (озвучка) ─► видео с дубляжом
```

- **Проекты.** Каждый ролик — папка с исходником, переводом, озвучкой и
  готовым видео. Мастер в четыре шага: исходник → голос → перевод → результат.
- **Перевод любой моделью.** LM Studio, Ollama, llama.cpp, KoboldCpp, Jan, vLLM
  или облако по ключу: OpenRouter (Claude, Gemini, GPT, DeepSeek, Qwen…),
  OpenAI, DeepSeek, Groq, Gemini. Плюс любой OpenAI-совместимый сервер.
- **Озвучка любым движком.** В комплекте OmniVoice (646 языков, точное
  попадание в длительность), Chatterbox Multilingual (23 языка, лицензия MIT) и
  «любой сервер `/v1/audio/speech`» (Kokoro-FastAPI, openedai-speech и др.).
  Свой движок подключается папкой с двумя функциями.
- **Голос оригинала.** Образец для клонирования программа вырезает из ролика
  сама. Можно взять свой образец или готовый голос движка.
- **Фон остаётся.** Demucs отделяет голос от музыки и шумов: музыка и шумы
  оригинала сохраняются в готовом ролике, а голос заменяется переводом.
- **Подгонка под тайминги.** Длинные фразы ускоряются движком или
  растягиваются во времени без смены тона. Паузы очищаются от шумов,
  громкость выравнивается до −16 LUFS.

## Что нужно

- Windows 10/11. Основной сценарий (проекты) написан на чистом Python и
  ffmpeg, но в macOS и Linux не проверялся. Часть инструментов запускается
  через PowerShell.
- [uv](https://docs.astral.sh/uv/) — ставит Python и зависимости сам.
- [ffmpeg](https://ffmpeg.org/) в `PATH`.
- Видеокарта NVIDIA желательна: Whisper и движки работают и на процессоре, но медленно.
- Модель перевода: локальная (например LM Studio с любой instruct-моделью) или ключ облачного сервиса.

## Установка

```bash
winget install --id=astral-sh.uv -e
```

```bash
winget install --id=Gyan.FFmpeg -e
```

Затем скачайте проект и запустите `Setup.bat` (один раз), потом `Start_UI.bat`.
Откроется `http://127.0.0.1:8768`.

При первом запуске откроются **Настройки**:

1. **Перевод (LLM).** Выберите, где работает модель, выберите модель из списка
   и нажмите «Проверить подключение». Для облака вставьте API-ключ: он хранится
   только у вас, в `config/secrets.local.json`.
2. **Озвучка (TTS).** Выберите движок и нажмите «Установить движок»: он
   поставится в свою папку со своим окружением. Если модель у вас уже стоит,
   укажите путь к её `python.exe`. Проверьте кнопкой «Озвучить пробную фразу».
3. **Отделение голоса от фона.** Установите Demucs. Без него проект тоже
   работает, но фон оригинала в ролик не попадёт.
4. **Whisper.** Модель распознавания: `medium` — баланс, `large-v3` — точнее.

## Как сделать дубляж

1. **Проекты → Новый дубляж:** перетащите видео или аудио и выберите язык перевода.
2. **Исходник:** «▶ Распознать и перевести» — или «Сделать всё сразу», если
   готовы довериться настройкам по умолчанию.
3. **Голос:** голос оригинала (по умолчанию), свой образец или голос движка →
   «▶ Озвучить».
4. **Перевод:** таблица фраз и отметки, как каждая легла в тайминг
   (влезает / ускорено / обрезано).
5. **Результат:** громкость голоса, фона и музыки → «▶ Собрать». Готовое
   видео, звук, отдельный голос и субтитры можно скачать или открыть в папке
   проекта.

Внизу всегда видна строка прогресса: шаг и проценты. Кнопка «Стоп» прерывает задачу.

**Инструменты** — отдельные операции без проекта: перевод и озвучка текста,
сценарий с эмоциями, транскрибация, обработка голоса, сведение с музыкой.

## Перевод: какие модели подходят

Все этапы, где нужна модель, используют один клиент (`llm_client.py`) и одну
настройку. Готовые пресеты лежат в `config/llm_providers.json`, новый сервис
добавляется одной записью.

| Где | Адрес по умолчанию | Ключ | Загрузка/выгрузка модели |
|---|---|---|---|
| LM Studio | `http://127.0.0.1:1234/v1` | — | да, автоматически |
| Ollama | `http://127.0.0.1:11434` | — | выгрузка после работы |
| llama.cpp / KoboldCpp / Jan / vLLM | свой порт | — | нет |
| OpenRouter, OpenAI, DeepSeek, Groq, Gemini | облако | да | — |
| Другой OpenAI-совместимый сервер | любой | по желанию | нет |

Ответы запрашиваются по JSON-схеме (structured output). Поэтому даже
маленькие локальные модели возвращают корректный результат. Если сервер схему
не понимает, клиент сам переходит на обычный запрос. Переводчик видит
несколько уже переведённых соседних фраз, так что термины и имена не скачут.

Ключи никогда не передаются в командной строке. Источники ключа по порядку:
переменная `DUB_LLM_API_KEY`, переменная сервиса (`OPENROUTER_API_KEY`,
`OPENAI_API_KEY`, …) и `config/secrets.local.json`.

## Движки

| Движок | Назначение | Клон голоса | Длительность | Лицензия |
|---|---|---|---|---|
| OmniVoice | озвучка, 646 языков | да | точная | код Apache-2.0, **веса CC-BY-NC** |
| Chatterbox Multilingual | озвучка, 23 языка | да | подгоняет ядро | **MIT**, можно в коммерции |
| Любой сервер `/v1/audio/speech` | озвучка | голоса сервера | подгоняет ядро | зависит от сервера |
| Demucs | отделение голоса от фона | — | — | **MIT** |

Как добавить свой движок: [engines/README.md](engines/README.md). Коротко —
скопировать `engines/_template`, описать модель в `engine.json`, написать
`load()` и `synthesize()` (или `separate()` для отделения фона). Поля
настроек интерфейс построит сам.

> **Лицензии моделей.** Программа бесплатная, но лицензии моделей задают их
> авторы. Веса OmniVoice разрешены только для некоммерческого использования. Если
> дублированные ролики приносят доход, выбирайте движок с открытой лицензией
> (например Chatterbox) и проверьте условия выбранной модели перевода.
> Клонируйте только голоса, на которые у вас есть согласие владельца.

## Командная строка

```bash
python project.py create clip.mp4 --target English
```

```bash
python project.py run projects/<id> all
```

```bash
python llm_client.py --llm-provider ollama --list-models
```

```bash
python dub.py projects/<id>/work/transcript.en.dub.jsonl --engine chatterbox --auto-fit --ref-audio voice.wav
```

```bash
python tts_engines.py --engine omnivoice --language en --text "Hello there"
```

Этапы проекта: `prepare` (звук → отделение фона → Whisper → перевод →
образец голоса), `voice` (озвучка), `export` (сведение и сборка видео),
`all` (всё подряд). Настройки движков берутся те же, что выбраны в интерфейсе.

## Структура

```
pipeline_ui.py        локальный сервер интерфейса (127.0.0.1)
ui/                   интерфейс: core.js, projects.js, tools.js, settings.js
project.py            проекты и их этапы
app_settings.py       общие настройки (config/settings.local.json)
llm_client.py         единый клиент LLM + config/llm_providers.json
translate_srt.py      перевод субтитров по фразам с таймингами
dub.py                ядро озвучки: тайминги, подгонка, сведение фраз
tts_engines.py        реестр движков и клиент воркера
engines/              движки озвучки и отделения фона (каждый в своём окружении)
tests/                тесты без моделей и видеокарты
```

Папка проекта:

```
projects/<дата>_<название>/
  project.json   настройки и состояние
  source/        исходник
  work/          звук, голос, фон, распознанный текст, план перевода, фразы
  voice/         образцы голоса
  output/        видео с дубляжом, сведённый звук, голос, субтитры
```

Тесты:

```bash
uv run python -m unittest discover tests
```

## Известные ограничения

- Правка перевода по фразам и переозвучка отдельных фраз пока в разработке:
  шаг «Перевод» только показывает результат.
- Один голос на весь ролик: разделения на говорящих пока нет.
- Один язык перевода на проект: для второго языка создайте ещё один проект.
- Python 3.10–3.12 для основного окружения (`uv` выберет сам).
