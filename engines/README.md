# Движки озвучки

Каждая папка здесь — один движок TTS. Программа находит их сама: новая папка
с `engine.json` сразу появляется в «Настройках».

| Папка | Движок | Клон голоса | Длительность | Лицензия |
|---|---|---|---|---|
| `omnivoice` | OmniVoice, 646 языков | да | точная | код Apache-2.0, веса **CC-BY-NC** (некоммерческая) |
| `chatterbox` | Chatterbox Multilingual, 23 языка | да | подгонка ядром | **MIT** (можно в коммерции) |
| `openai_speech` | любой сервер `/v1/audio/speech` | нет, голоса сервера | подгонка ядром | зависит от сервера |
| `_template` | шаблон для своего движка | — | — | — |
| `demucs` | Demucs: отделение голоса от фона | — | — | **MIT** |
| `sherpa_diarization` | Sherpa-ONNX: кто и когда говорит | — | — | **Apache-2.0** / MIT |

## Как это устроено

```
dub.py (ядро)  ──JSON-строки──►  engines/worker.py  ──►  engines/<id>/adapter.py
 тайминги, подгонка,               своё окружение          load() + synthesize()
 сведение, нормализация            движка (.venv)
```

У каждого движка своё окружение Python: модели требуют разные версии
torch/transformers, и в одном окружении они не уживаются. Ядро запускает
`worker.py` интерпретатором движка и обменивается с ним строками JSON.
Всё, что не связано с самой моделью — попадание в тайминги, ускорение длинных
фраз, обрезка с затуханием, очистка пауз, сведение, — делает ядро. Поэтому
адаптер получается коротким.

## Как добавить свой движок

1. Скопируйте `_template` в `engines/my_tts` (имя папки = id движка, без `_` в начале).
2. В `engine.json` впишите название, лицензию, языки и что умеет модель:
   - `voice_clone` — клонирует голос по образцу (`voice.ref_audio`, `voice.ref_text`);
   - `voice_list` — у модели есть готовые голоса (`voice.voice_id`), плюс функция `list_voices`;
   - `duration` — модель умеет говорить заданное число секунд (иначе ядро подгонит само);
   - `speed` — понимает скорость речи (иначе ядро ускорит растяжением во времени);
   - `instruct` — понимает текстовые подсказки к голосу.

   Поля из `settings` интерфейс покажет сам. Типы: `int`, `float`, `text`, `select` (+ `options`), `bool`; `advanced: true` прячет поле в «Дополнительно».

   Описания можно писать по-английски: они покажутся как есть на любом языке
   интерфейса. Русские тексты переводятся через `locales/en.json`; тест
   `tests/test_i18n.py` подскажет, каких переводов не хватает.
3. В `adapter.py` реализуйте две функции:

   ```python
   def load(settings, device):
       ...  # загрузить модель один раз
       return {"sample_rate": 24000}

   def synthesize(text, language=None, voice=None, duration=None, speed=1.0, hints=None):
       ...  # одна фраза
       return audio, sample_rate   # моно float32 numpy, значения -1..1
   ```

4. В `pyproject.toml` перечислите зависимости модели.
5. Откройте «Настройки» и нажмите «Установить движок» (внутри выполняется
   `uv sync --project engines/my_tts`). Либо укажите путь к уже готовому
   окружению: он сохранится в `engine.local.json` (этот файл не попадает в git).

Проверка из командной строки:

```bash
python tts_engines.py
python tts_engines.py --engine my_tts --language en --text "Hello there"
```

## Движок отделения голоса от фона

Устроен так же, но в `engine.json` указано `"kind": "separator"`, а вместо
`synthesize()` реализована функция `separate()`:

```python
def separate(input_path, out_dir):
    ...  # разделить микс
    return {"vocals": ".../vocals.wav", "background": ".../background.wav"}
```

Такие движки показываются в настройках в разделе «Отделение голоса от фона».
Пример — папка `demucs`. Прогресс можно печатать строками
`PROGRESS 40/100 Текст`: интерфейс покажет его в строке прогресса.

## Движок разделения на говорящих

В `engine.json` указано `"kind": "diarizer"`, а адаптер реализует `diarize()`:

```python
def diarize(input_path, num_speakers=None):
    ...  # input_path — моно WAV 16 кГц; num_speakers=None — определить число самому
    return {"turns": [{"start": 0.0, "end": 2.5, "speaker": 0}, ...]}
```

Остальное делает ядро: раздаёт фразы Whisper говорящим (фраза, где голос
меняется, делится по словам), вырезает образец голоса каждого и озвучивает
каждого своим голосом. Пример — папка `sherpa_diarization`: границы реплик
находит sherpa-onnx, а реплики группирует по голосовым отпечаткам
`clustering.py` (только numpy, проверяется тестами без движка). Движки,
которые работают только на процессоре, ставят в `engine.json`
`"cpu_only": true`, и выбор устройства в настройках не показывается.

## Если движок — это сервер

Если модель уже работает как сервер с OpenAI-совместимым методом
`/v1/audio/speech` (Kokoro-FastAPI, Chatterbox-TTS-Server, openedai-speech,
AllTalk и др.), писать адаптер не нужно: выберите движок «Любой сервер
/v1/audio/speech» и укажите адрес.

Для серверов с другим API скопируйте `openai_speech`, поменяйте запрос в
`adapter.py` и оставьте в `engine.json` `"runtime": "main"`: такому движку не
нужно своё окружение. Ключ API, если он нужен, программа передаёт в
переменной окружения `DUB_TTS_API_KEY`.
